# Bug Log — Ashen Crown

Every bug/gap found during play, categorized and dated, so **recurrence patterns are visible over time** — not just "was this fixed" (that's `system-register.md`'s job) but "how many times has this *category* of thing gone wrong." Governed by `.claude/rules/bug-protocol.md`.

**Loaded every session** (`dm-start-session` step 1) specifically so a repeat in the same category is noticed immediately, not rediscovered from scratch.

**Archived, 2026-09-03**: this file only keeps the Log table's most recent 3 distinct dates in full — older entries live in `bug-log-archive.md` (same format, full detail), moved there by `py .claude/scripts/log_archive.py ashen-crown --target bug-log` (generalized the same day from a bug-log-only script into one that also archives `system-register.md`). The Category frequency table below always reflects the complete history, archived entries included — only the detailed entry text moves, never the counts. Re-run the script (`--dry-run` first to preview) once this file's own Log table starts growing large again.
